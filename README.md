# منظومة عروض الإيفنت وإحالات العزومة (EventPass) 🎯

تطبيق ويب متكامل مصمم للكاشير والمنظمين لإدارة عروض الإيفنت، وتوثيق بيانات الطلاب المشتريين وربطهم بأصحاب العزومة:
- **الطالب المشتري (الضيف):** خصم **10%** فوري على أوردره (لمرة واحدة فقط كمدعو).
- **صاحب العزومة (المُضيف):** يجمع **5 أصدقاء** طلبوا على الـ ID بتاعه، ويكسب **مشروب مجاني واحد فقط (1 Free Drink)** لمنع التكرار والتلاعب.
- **جمع البيانات (CRM & Leads):** تسجيل الاسم بالكامل، رقم الموبايل، والـ ID مع زر تحميل شيت إكسل (CSV) في أي وقت.

---

## 🚀 1. رفع المشروع على GitHub (خطوتين فقط)

المشروع جاهز ومسجل محلياً بـ Git. لرفعه على حسابك في GitHub:

1. افتح موقع [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم مثلاً `event-pass`.
2. في موجه الأوامر (Terminal) داخل مجلد المشروع، اكتب الأمرين التاليين (مع استبدال الرابط برابط مستودعك):
```bash
git remote add origin https://github.com/<YOUR_USERNAME>/event-pass.git
git branch -M main
git push -u origin main
```

---

## ☁️ 2. تشغيل التطبيق أونلاين على السحاب (لينك مباشر يفتح على أي موبايل)

أسهل وأفضل منصة مجانية لتشغيل التطبيق وقاعدة البيانات أونلاين برابط مباشر (HTTPS) هي **Render**:

1. افتح موقع [Render.com](https://render.com) وسجل دخولك بحساب الـ GitHub.
2. اضغط على **"New +"** ثم اختر **"Web Service"**.
3. اختر مستودع المشروع `event-pass` من القائمة.
4. اترك الإعدادات كما هي (تم تجهيز ملف `render.yaml` تلقائياً ليضبط كل شيء):
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm run server`
5. اضغط **"Deploy"**.

في أقل من دقيقتين ستمنحك المنصة رابطاً مباشراً مثل:
```
https://event-pass-xxxx.onrender.com
```
هذا الرابط يعمل على أي هاتف (آيفون أو أندرويد) عبر باقة الموبايل (4G/5G) أو أي شبكة واي فاي دون أي قيود!

---

## 💻 3. التشغيل المحلي (Offline / Wi-Fi)

لتشغيل التطبيق محلياً على جهازك:
```bash
npm run server
```
* من اللابتوب: `http://localhost:5000`
* من هواتف المنظمين على نفس شبكة الواي فاي: الرابط الموضح في شاشة السيرفر (مثال `http://192.168.1.6:5000`).

# منظومة إدارة تسجيل إيفنت الطلاب والعروض (EventPass) 🎯

تطبيق ويب متكامل مصمم خصيصاً لاستخدام **أصحاب المكان والمنظمين (Staff Only)** لتسجيل الطلاب في الإيفنت، وتطبيق عروض:
- **صاحب الدعوة (Host):** مشروب مجاني (Free Drink) 🥤
- **الصحابه والمرافقين (Guests):** خصم على الطلبات 🏷️
- **منع التكرار (Fraud Prevention):** فحص فوري يمنع أي طالب أو صاحب دعوة من أخذ العرض مرتين لنفس الـ ID.

---

## 🚀 كيفية التشغيل السريع

### 1. تشغيل التطبيق بالكامل (الخادم والواجهة معاً):
في موجه الأوامر (Terminal):
```bash
npm run server
```
أو لوضع التطوير:
```bash
npm start
```

### 2. فتح التطبيق:
* **من اللابتوب / الكاشير:** افتح المتصفح على:
  ```
  http://localhost:5000
  ```
* **من موبايلات المنظمين في الصالة / على الأبواب:**
  تأكد أن الموبايلات متصلة بنفس شبكة الواي فاي (Wi-Fi) الخاصة بالمكان، وافتح الرابط الموضح في شاشة الخادم (مثال):
  ```
  http://192.168.1.6:5000
  ```

## 📱 مميزات التطبيق

1. **واجهة موبايل سريعة وسلسة (Mobile-First UI):**
   - أزرار إدخال واضحة مناسبة لسرعة التعامل في الطوابير والزحمة.
   - دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
2. **فحص لحظي للـ ID (Instant Duplicate Detection):**
   - بمجرد كتابة الـ ID يتم فحص قاعدة البيانات فوراً.
   - يظهر تنبيه أحمر لو الطالب مسجل مسبقاً، مع تفاصيل توقيت تسجيله ومع أي منظم.
3. **ماسح باركود بالكاميرا (Barcode / QR Scanner):**
   - يمكن تشغيل الكاميرا من داخل التطبيق لمسح باركود كارنيه الطالب مباشرة بدون كتابة يدوية.
4. **تأكيد العرض وبطاقة استحقاق بصرية:**
   - شاشة واضحة ومبهجة تؤكد استحقاق فري درينك لصاحب الدعوة والخصم للمرافقين، مع تأثير الاحتفال (Confetti).
   - زر سريع لتجهيز الشاشة للمجموعة التالية في ثانية واحدة.
5. **شاشة بحث وتحقق (Instant Lookup):**
   - للبحث عن أي طالب برقم الـ ID للتأكد من حالته ومن الذي قام بدعوته.
6. **لوحة إحصائيات حية (Live Dashboard):**
   - عداد مباشر للطلاب الحاضرين، المجموعات، المشروبات المجانية، والخصومات.
   - زر تصدير ملف **Excel (CSV)** بجميع بيانات الحضور للاحتفاظ بها بعد انتهاء الإيفنت.
7. **إعدادات مرنة وقابلة للتخصيص:**
   - تغيير اسم الإيفنت واسم المكان.
   - تحديد الحد الأدنى لعدد الصحاب المطلوب لتفعيل المشروب المجاني.
   - تغيير نسبة الخصم.
   - تصفير البيانات برمز حماية (PIN الافتراضي: `1234`).
